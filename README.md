# Windows 10 Client Deployment and Systems Administration

This repository documents the end-to-end deployment, configuration, and administration of Windows 10 Enterprise client operating systems within a virtualized Hyper-V lab environment. 

The project spans five core systems administration disciplines, beginning with Generation 2 virtual machine provisioning, OS installation, and localized device identification. Native system utilities were utilized for automated maintenance via Task Scheduler and hardware troubleshooting through Device Manager. Advanced local storage management was implemented using Storage Spaces with two-way mirror and parity resiliency models.

Furthermore, local identity management was structured with department-aligned user accounts and security groups, while enterprise-grade endpoint security was enforced through comprehensive Local Group Policy hardening covering account lockout policies, password complexity, and user account control baselines.
